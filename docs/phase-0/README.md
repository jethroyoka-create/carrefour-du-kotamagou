# Dossier Phase 0 — Carrefour du Kotamagou

**Projet :** Carrefour du Kotamagou  
**Objet :** Étude éditoriale, documentaire et technique préalable à la conception et au développement (Phase 0).  
**Date :** 12 novembre 2026  
**Statut :** Phase 0 uniquement — aucun code applicatif, aucune dépendance et aucun composant n'ont été créés.

---

## Règles de lecture et de rigueur documentaire

Dans l'ensemble des documents de ce dossier :
- **[FAIT VÉRIFIÉ]** désigne une information directement observée dans les sources publiques accessibles (chaîne YouTube `@carrefourdukoutammakou-lz3cq`, métadonnées OpenGraph publiques Facebook, résultats de recherche web vérifiés, fichiers et outils locaux).
- **[HYPOTHÈSE]** désigne une interprétation plausible nécessitant confirmation humaine ou accès interne (ex. contenu détaillé des comptes TikTok/Facebook non consultables publiquement).
- **[RECOMMANDATION]** désigne un choix éditorial, UX, organisationnel ou technique proposé par l'équipe d'étude.

## Compétences (Skills) mobilisées après vérification

Les recommandations de ce dossier s'appuient sur les compétences vérifiées présentes dans l'environnement :
- `superpowers` (`using-superpowers`, `brainstorming`) : cadrage méthodologique avant toute conception technique ;
- `saas-factory` : séparation MVP / évolutions ultérieures, analyse des contraintes produit ;
- `senior-backend-dev` : modélisation relationnelle, architecture, compromis d'hébergement et sécurité ;
- `ui-ux-pro-max`, `frontend-design`, `design-system`, `brand`, `banner-design` : direction artistique *Journalisme de terre et de mémoire*, typographie, accessibilité et système de tokens.
